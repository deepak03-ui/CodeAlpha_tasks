# HealthPredict AI

HealthPredict AI is a modern healthcare risk prediction platform that uses Machine Learning models to analyze medical parameters and estimate disease risk probabilities.

The platform supports prediction for:

- Heart Disease
- Diabetes
- Breast Cancer

The system combines a modern React frontend with a Flask backend and trained Machine Learning models for real-time clinical risk analysis.

---

# Features

- AI-powered disease prediction
- Heart Disease risk analysis
- Diabetes prediction system
- Breast Cancer detection support
- Probability-based prediction results
- Animated analytics dashboard
- Responsive modern UI
- Real-time backend integration
- Machine Learning model inference
